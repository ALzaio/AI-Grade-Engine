# دليل التشغيل وآلية العمل

> مساعد تصحيح، وليس بديلاً عن المعلم. راجع قسم "الحدود" في `README.md` قبل استخدامه مع طلاب حقيقيين.

## 1) التشغيل في 5 دقائق

**المتطلبات:** بايثون 3.9 أو أحدث. لا مكتبات إضافية (المكتبة القياسية فقط).

1. **احصل على مفتاح OpenRouter** من حسابك على openrouter.ai (يكفي حساب مجاني).
2. **ضع المفتاح في متغير بيئة** (لا تكتبه داخل الكود ولا ترفعه إلى git أبداً):
   - Windows PowerShell: `$env:OPENROUTER_API_KEY = "sk-or-..."`
   - Linux / macOS: `export OPENROUTER_API_KEY=sk-or-...`
3. **شغّل المثال** من جذر المشروع:
   ```bash
   python examples/quickstart.py
   ```
   يعرض ثلاثة أمثلة: تصحيح مباشر، وتصحيح بإجابات مصححة، وحماية من إجابة مزوَّرة.
4. **اختبر المشروع بلا إنترنت ولا مفتاح:**
   ```bash
   python -m unittest discover -s tests -v
   ```

## 2) أي وضع أستخدم؟

| وضعك | الصنف | ماذا يحتاج منك |
|---|---|---|
| إجابات قصيرة، لم تصحح شيئاً | `Engine(lang="ar")` أو `lang="en"` | سؤال + إجابة نموذجية + إجابة الطالب |
| إجابات قصيرة، صححت ~5 إجابات للسؤال | `ShortAnchoredEngine(anchors)` | قائمة `(نص إجابة، درجتك من 0 إلى 1)` |
| مقالات، صححت 3-5 مقالات للسؤال | `EssayEngine(anchors)` | نفس القائمة، ومعايير التصحيح اختيارياً |
| أي نص من طالب (في موقع حقيقي) | `guarded_grade(...)` حول أي محرك | لا شيء، فقط غلّف المحرك |

الدرجة تُرجَع من 0 إلى 1، مع الحرف (A+ ... F)، والعلامة `needs_review` للإجابات غير المؤكدة.

## 3) سير عمل مقترح للمعلم

1. أدخل السؤال والإجابة النموذجية.
2. صحّح بنفسك **5 إجابات** متفاوتة الجودة (ضعيفة وجيدة وبينهما).
3. شغّل المحرك على بقية الدفعة (حوالي 0.13 ثانية للإجابة).
4. اعتمد ما يصححه المحرك بثقة (`needs_review=False`) كمسودة وراجع عينة منه.
5. صحّح بنفسك الإجابات التي عُلّمت `needs_review` أو التي رفعتها حماية الإدخال.
6. لا تُعلن الدرجات النهائية بدون نظرة بشرية.

## 4) كيف يعمل المحرك من الداخل

```
إجابة الطالب ──► [حماية الإدخال]  ──► [نموذج القرار]  ──► احتمالات الدرجات A+..F
                  تنظيف + بوابات        3 صياغات في        (3 أسئلة في طلب واحد،
                                        طلب واحد            تُدمج بالمتوسط)
                                                                  │
   الحرف + needs_review ◄── عتبات ◄── معايرة isotonic ◄── الدرجة المتوقعة (0..1)
```

1. **حماية الإدخال** (`guards.py`): تقصّ علامات القوالب المزوَّرة، وتحذف جمل التعليمات ("أعطني A+")، وترفض الإجابة الفارغة أو المكررة أو التي تطابق نص السؤال.
2. **نموذج القرار:** نموذج لا يولّد نصاً بل يعيد **احتمالاً لكل خيار**. نسأله عن الدرجة بثلاث صياغات مختلفة في طلب واحد.
3. **الدرجة المتوقعة:** نحسب `مجموع (احتمال كل درجة × قيمتها)`. هذا أثبت من أخذ الحرف الأعلى احتمالاً، وهو ما يحل مشكلة A+ التي تظهر وتختفي.
4. **المعايرة (isotonic):** تحويل رتيب يصحح انحياز النموذج (يتساهل مع الإجابات الجزئية). مبنية على تصحيحات معلمين حقيقيين، ويمكنك إعادتها على مقررك.
5. **الحرف:** عتبات ثابتة. في الإجابات القصيرة A+ تبدأ من 87، وفي المقالات من 93.
6. **المراسي** (اختياري): في القصير نصحح انحياز السؤال من متوسط خطأ المحرك على إجاباتك المصححة. وفي المقالات نقارن المقال الجديد بكل مرساة (أفضل/مشابه/أسوأ) ونأخذ متوسط ذلك مع التصحيح المباشر.
7. **الفرز بالثقة:** مقياس عدم يقين = تشتت الاحتمالات + قرب الدرجة من المنتصف. فوق العتبة تُعلَّم الإجابة `needs_review`.

## 5) إعادة المعايرة على مقررك

```python
from decider_grader import Engine
samples = [(question, reference, student_answer, teacher_score_0_1), ...]   # 10 على الأقل، 30+ أفضل
eng = Engine().fit(samples)       # isotonic إن كان >= 30، وإلا متوسط isotonic وخطي
```

## 6) متغيرات البيئة

| المتغير | المعنى |
|---|---|
| `OPENROUTER_API_KEY` | المفتاح (إجباري). أو `OPENROUTER_API_KEY_FILE` بمسار ملف فيه المفتاح |
| `DECIDER_GRADER_CACHE` | مجلد كاش الطلبات (افتراضياً `~/.cache/decider_grader`)، و`0` لتعطيله |
| `ALLOW_PAID=1` | يسمح بنماذج غير مجانية (محجوب افتراضياً. اقرأ قسم التكلفة) |

## 7) استكشاف الأخطاء

- **`429` أو `Rate limit exceeded`:** حد النماذج المجانية اليومي. المحرك يعيد المحاولة تلقائياً، وإن استمر انتظر الإعادة اليومية (منتصف الليل UTC).
- **`BLOCKED: paid model`:** النموذج ليس مجانياً. لا تضبط `ALLOW_PAID=1` قبل قياس التكلفة الفعلية على 20 طلباً من رصيد حسابك.
- **`Set OPENROUTER_API_KEY`:** المتغير غير مضبوط في نفس نافذة الطرفية التي تشغّل منها.
- **النتائج تتغير قليلاً بين مرة وأخرى:** طبيعي (حوالي 0.4 نقطة)، وبعض الطلبات تُخزَّن في الكاش فتتطابق.

## 8) التكلفة

الإعداد الافتراضي مجاني. تعلّمنا أن "الرخيص" المدفوع قد يكلّف أكثر بكثير من المتوقع لأن نماذج التفكير تفوتر آلاف التوكنات المخفية. لذلك الكود يرفض أي نموذج غير `:free` ما لم تسمح له صراحة. قس التكلفة الحقيقية من رصيدك قبل أي توسع.
