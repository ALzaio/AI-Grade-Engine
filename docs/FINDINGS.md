## Round 14 -- novel ideas (real data)
Lexical features / "addresses the question" / claim-precision / residual stacking: AES 15.7 -> 14.2-14.9% at best, short sets unchanged or worse. Not worth it.
**Anchored pairwise comparison (AnchoredEngine)**: teacher grades ~5 anchor answers per question (spanning low..high); decider compares NEW vs each ANCHOR (better/similar/worse); score = mean(anchor_score + delta*2*(P(better)-P(worse))).
AR-AES essays (n=120, anchors = other essays of the same question, leave-one-out): k=5 delta=.4 MAE 11.9% pearson .858 within10 57% within20 82%  (human-human 12.2% / 58% / 77%; direct+iso 15.7% / 33% / 72%).
Robust: k=3 12.8% | k=9 12.1% | delta .55 12.6% | .7 13.1% | order-swapped 13.0% | 'similar'-weighted 12.3%. Weak-answer bias +40 pts -> +10 pts. Spread of per-anchor estimates as uncertainty: auto 60% -> MAE 10.5%, 50% -> 9.9% (corr .195, modest).
BUT on short answers (AR-ASAG) anchored is WORSE: 14.4-15.7% vs 12.9% direct+iso. => use anchored for essays, direct+calibration for short answers.
Caveats: delta picked from {.25,.4,.55,.7} on the same data (mild optimism); anchors were stratified across the score range; needs ~5 teacher-graded anchors per question.
